# 02-03-HCEF

This file defines the crystal electric-field term $H_{\mathrm{cef}}$.
Reference link is defined in `./standards/en/02-hamiltonian/02-00-LOCAL_HAMILTONIAN.md` only.
Kramers-doublet canonicalization and g-tensor rules are defined in
`./standards/en/03-spectrum/03-02-KRAMERS_DOUBLET.md`.

## 1) Generic Stevens Form (MUST)
MUST:
- Use Stevens-operator expansion.
- Keep one consistent energy unit across all $B_k^q$.

Math:
$$
H_{\mathrm{cef}} = \sum_{k,q} B_k^q O_k^q.
$$

Code form:
```text
H_cef = sum_{k,q} B[k,q] * O[k,q]
```

Index:
- `B_k^q`: CEF coefficients.
- `O_k^q`: Stevens operators.

Validation:
- Output matrix must be Hermitian.

## 2) Oh Branch (MUST)
MUST:
- Use only the cubic-allowed combination below.

Math:
$$
H_{\mathrm{cef}}^{Oh}
= B_4\left(O_4^0 + 5 O_4^{4,c}\right)
+ B_6\left(O_6^0 - 21 O_6^{4,c}\right).
$$

Equivalent parameter map:
Math:
$$
B_{40}=B_4,\quad B_{44}=5B_4,\quad B_{60}=B_6,\quad B_{64}=-21B_6.
$$

Code form:
```text
H_cef_Oh = B4*(O40 + 5*O44c) + B6*(O60 - 21*O64c)
```

Validation:
- No additional Oh terms are allowed.

## 3) C3v Branch (MUST)
MUST:
- Allow exactly six terms:
  $O_2^0, O_4^0, O_6^0, O_6^6, O_4^{3,\eta}, O_6^{3,\eta}$.
- For $q=3$ terms, `eta` must be either cosine (`c`) or sine (`s`) mode.
- Project axis convention for this project is fixed as:
  `c -> z`, `a -> y`.

Math:
$$
H_{\mathrm{cef}}^{C3v}
= B_{20} O_2^0 + B_{40} O_4^0 + B_{60} O_6^0
+ B_{66} O_6^6 + B_{43} O_4^{3,\eta} + B_{63} O_6^{3,\eta},
\quad \eta\in\{c,s\}.
$$

Code form:
```text
H_cef_C3v = B20*O20 + B40*O40 + B60*O60 + B66*O66 + B43*O43_eta + B63*O63_eta
```

Validation:
- Only the six terms above are legal in this standard.

## 4) Cos/Sin Interface Rule (MUST)
MUST:
- Standards default representation is cosine mode for $q=3$ terms.
- Runtime may switch to sine mode explicitly.
- Project runtime default currently opens sine mode when requested by input flags.

Code form:
```text
mode_q3 in {"cos", "sin"}
# interface default: cos
# runtime call may set sin mode explicitly
```

Validation:
- `mode_q3` must be recorded in metadata.

## 5) Implementation Contract (MUST)
Use this order:
1. Select symmetry branch (`Oh` or `C3v`).
2. If `C3v`, select `mode_q3` (`cos` or `sin`).
3. Build the CEF matrix in one fixed basis.

Current reference implementation uses the fixed-`J` `|J,M\rangle` basis
directly:

Math:
$$
H_{\mathrm{cef}}^{(J)} = \sum_{k,q} B_k^q O_k^q.
$$

An optional extended route may first build a one-body CEF matrix
$h^{\mathrm{cef}}_{pq}$ and then lift to a many-body operator:

Math:
$$
H_{\mathrm{cef}} = \sum_{p,q} h^{\mathrm{cef}}_{pq}\,c_p^\dagger c_q.
$$

Code form:
```text
reference:
  H_cef_J = sum_{k,q} B[k,q] * O[k,q]

optional extended route:
  H_cef_many = sum_{p,q} h_cef[p,q] * cdag(p) * c(q)
```

Validation:
- Output matrix must be Hermitian.
- If a lifted one-body/many-body object is exported, its metadata must follow
  `./standards/en/01-core/01-02-OPERATOR_IMPLEMENTATION.md`.

## 6) Stevens Operator Computation (MUST)
Stevens operators $O_k^q$ are Hermitian operators built from $J_z,J_+,J_-$ in a
$(2J+1)$-dimensional $\lvert J,M\rangle$ basis.
Convention: Hutchings 1964 (Solid State Physics vol. 16) with Condon-Shortley phase.

Cross-reference:
- This section specifies the CEF-required subset only.
- Full generalized Stevens definitions are normative in
  `01-core/01-03-STEVENS_OPERATORS.md`.

### 6.1 Basis matrices
Build $J_z,J_+,J_-$ in the $\lvert J,M\rangle$ basis ($M=-J,\ldots,J$, ascending):

Math:
$$
(J_z)_{MM'}=M\,\delta_{MM'},\qquad
(J_+)_{M+1,M}=\sqrt{J(J+1)-M(M+1)},\qquad
J_-=J_+^\dagger.
$$

Define $X\equiv J(J+1)$ and $\mathbf 1$ as the identity.

### 6.2 Diagonal Stevens operators ($q=0$)

Math:
$$
O_2^0 = 3J_z^2-X\mathbf1,
$$

$$
O_4^0 = 35J_z^4-(30X-25)J_z^2+(3X^2-6X)\mathbf1,
$$

$$
O_6^0 = 231J_z^6-(315X-735)J_z^4+(105X^2-525X+294)J_z^2
       -(5X^3-40X^2+60X)\mathbf1.
$$

### 6.3 Off-diagonal Stevens operators ($q\neq0$)
Use tesseral (cosine/sine) form.
For each $q>0$, define the symmetrized product $\{A,B\}_+=AB+BA$.

Oh branch operators:

Math:
$$
O_4^{4,c}=\tfrac{1}{2}(J_+^4+J_-^4),
$$

$$
O_6^{4,c}=\tfrac{1}{4}\bigl\{(11J_z^2-X\mathbf1-38\mathbf1),\;J_+^4+J_-^4\bigr\}_+.
$$

C3v additional operators:

Math:
$$
O_4^{3,c}=\tfrac{1}{4}\bigl\{J_z,\;J_+^3+J_-^3\bigr\}_+,
\qquad
O_4^{3,s}=\tfrac{1}{4i}\bigl\{J_z,\;J_+^3-J_-^3\bigr\}_+,
$$

$$
O_6^{3,c}=\tfrac{1}{4}\bigl\{(11J_z^3-(3X+59)J_z),\;
J_+^3+J_-^3\bigr\}_+,
$$

$$
O_6^{3,s}=\tfrac{1}{4i}\bigl\{(11J_z^3-(3X+59)J_z),\;
J_+^3-J_-^3\bigr\}_+,
$$

$$
O_6^{6}=\tfrac{1}{2}(J_+^6+J_-^6).
$$

### 6.4 Implementation recipe

Code form:
```text
Jz, Jp, Jm = build_J_matrices(J)
X = J*(J+1)

# diagonal
O20 = 3*Jz@Jz - X*I
O40 = 35*Jz4 - (30*X-25)*Jz2 + (3*X**2-6*X)*I
O60 = 231*Jz6 - (315*X-735)*Jz4 + (105*X**2-525*X+294)*Jz2 - (5*X**3-40*X**2+60*X)*I

# Oh off-diagonal
Jp4 = Jp@Jp@Jp@Jp;  Jm4 = Jm@Jm@Jm@Jm
O44c = 0.5*(Jp4 + Jm4)
P4 = 11*Jz@Jz - X*I - 38*I
O64c = 0.25*(P4@(Jp4+Jm4) + (Jp4+Jm4)@P4)

# C3v off-diagonal
Jp3 = Jp@Jp@Jp;  Jm3 = Jm@Jm@Jm
O43c = 0.25*(Jz@(Jp3+Jm3) + (Jp3+Jm3)@Jz)
O43s = 0.25/1j*(Jz@(Jp3-Jm3) + (Jp3-Jm3)@Jz)
P3 = 11*Jz@Jz@Jz - (3*X+59)*Jz
O63c = 0.25*(P3@(Jp3+Jm3) + (Jp3+Jm3)@P3)
O63s = 0.25/1j*(P3@(Jp3-Jm3) + (Jp3-Jm3)@P3)
Jp6 = Jp@Jp@Jp@Jp@Jp@Jp;  Jm6 = Jm@Jm@Jm@Jm@Jm@Jm
O66 = 0.5*(Jp6 + Jm6)
```

Validation:
- All Stevens operators must be Hermitian: $O_k^{q}=(O_k^{q})^\dagger$.
- $O_k^0$ must be diagonal in $\lvert J,M\rangle$ basis.
- Matrix dimension must be $(2J+1)\times(2J+1)$.
