# 05-00-IO

This file defines the **normative** disk I/O contract for cross-module artifacts.
All rules here are MUST-level constraints.
Non-normative directory examples are moved to `./standards/en/05-io/05-01-IO_LAYOUT.md`.

## 1) Scope (MUST)
MUST:
- This file defines disk I/O contracts only.
- Physics semantics remain in `03-00/03-01/04-00/04-01/04-02/04-03`.
- Runtime numeric/input gates are inherited from
  `./standards/en/06-utils/06-00-RUNTIME_NUMERICS.md`.

Code form:
```text
io_contract_scope = {paths, filenames, metadata, key, read-first policy}
```

Validation:
- Any artifact violating this contract is invalid for downstream reuse.

## 2) Root and Stage Anchors (MUST)
MUST:
- All persisted artifacts must be under `./outputs/`.
- Runtime input field `paths.output_root` is mandatory, and in this standard
  version it must be exactly `./outputs` (no alternative output root).
- `L0` disk anchor is `./outputs/core/L0/`.
- `LMSM/LSJM/ligand` disk anchors are under `./outputs/core/...`.
- In `model.scheme = "RS"`, `L1` is under `./outputs/core/L1/F/...`.
- In `model.scheme = "ED"`, `IONED` and `L1/F` are under
  `./outputs/<run_name>/...`.
- Material/runtime stages `L2/L3/L4` are under `./outputs/<run_name>/...`.

Code form:
```text
root_outputs = ./outputs
anchor_L0    = ./outputs/core/L0
anchor_core  = ./outputs/core
anchor_run   = ./outputs/<run_name>
```

Validation:
- Any stage output outside `./outputs/` is a contract failure.

## 3) Contracted Path Tokens (MUST)
MUST:
- Core LMSM/LSJM/L1-F path must include:
  `n-{n}_r42-{r42}_r62-{r62}_scheme-{scheme}`.
- ED still stores reference LMSM/LSJM under `scheme-RS`; the ED choice is
  represented by run-scoped `IONED` and `L1/F` artifacts.
- Ratio tokens `r42/r62` in path/key are derived values from runtime input:
  `r42 = F4/F2`, `r62 = F6/F2` (`F2 != 0`).
- If adjacent-sector `f^(n-1)` / `f^(n+1)` LSMS/LSJM inputs differ from the
  legacy shared-ratio model, implementations may insert one extra path token
  `branchsig-{hash}` under `core/L1/F/{core_token}/`.
- L2 is placed directly under `./outputs/<run_name>/L2`.
- IONED sector artifacts are placed under `./outputs/<run_name>/IONED/n-{n}`.
- ED `L1/F` is placed directly under `./outputs/<run_name>/L1/F`.
- SOPT L3 is placed under `./outputs/<run_name>/L3/U-{U}_Jh-{Jh}`.
- FOPT L3 is placed under
  `./outputs/<run_name>/L3/U-{U}_Jh-{Jh}_lig1.U_p-{U_p1}_lig2.U_p-{U_p2}`.
- SOPT L4 is placed under
  `./outputs/<run_name>/L4/U-{U}_Jh-{Jh}/kramer-{kramer_name}`.
- If denominator parameters or main-sector reference mode differ from the
  legacy zero-reference shared-parameter model,
  implementations may insert one extra path token `denomsig-{hash}` between
  `U-{U}_Jh-{Jh}_z-{zeta}` and `L3/kramer/...`.
- L2 paths must include `run_name` and must not require `U/Jh/zeta` tokens.
- L3 paths include only scan parameters; system parameters are recorded in
  `<run_name>/source.txt`.
- Numeric serialization for path tokens is fixed-point with 8 decimals.
- Key/hash serialization remains fixed-point with 12 decimals.

Code form:
```text
fmt8(x) = format(x, ".8f")
fmt12(x) = format(x, ".12f")  # key/hash only
r42 = F4 / F2
r62 = F6 / F2
core_dir = n-{n}_r42-{fmt8(r42)}_r62-{fmt8(r62)}_scheme-{scheme}
branch_dir = branchsig-{hash}          # optional
run_dir = <run_name>
u_jh_dir = U-{fmt8(U)}_Jh-{fmt8(Jh)}
```

Validation:
- Mismatch in token set or numeric formatting is a key/path mismatch.

## 4) Required Artifact Filenames (MUST)
MUST:
- `core/L0` anchor must contain:
  - `f_create_{n}_to_{n+1}.npz`, `f_create_{n-1}_to_{n}.npz`
  - FOPT additionally uses `p_create_4_to_5.npz`, `p_create_5_to_6.npz`
  - `meta.json`
- `LMSM` and `LSJM` must contain:
  - `{LEVEL}.npz`, `source.txt`, `meta.json`
- `core/ligand/{soc,nsoc}/n-{N}` must contain:
  - `data.npz`, `source.txt`, `meta.json`
- `IONED/n-{N}` must contain:
  - `states.npz`, `meta.json`
- `L1/L2/L3/L4` must contain:
  - `data.npz`, `meta.json`
- A run with `runtime.run_name` writes:
  - `<output_root>/<run_name>/run.log`
- FOPT L3 additionally writes:
  - `exchange.txt` as a human-readable total/process exchange sidecar
- SOPT L4 additionally writes `exchange.txt` when `J_mu` is available.
- FOPT L2 stores one file per pair:
  - `V_plus_f1_lig1.npz`, `V_plus_f1_lig2.npz`,
    `V_plus_f2_lig1.npz`, `V_plus_f2_lig2.npz`, `meta.json`
- `spin12` (module 04-03, optional stage) uses:
  - `data.npz`, `meta.json`

Code form:
```text
required_files_L1_L4 = {data.npz, meta.json}
required_files_LMSM_LSJM = {{LEVEL}.npz, source.txt, meta.json}
```

Validation:
- Missing required filenames blocks cache reuse.

## 5) Payload Meaning Map (MUST)
MUST:
- `core/L0/f_create_{n}_to_{n+1}.npz` -> f-shell creation primitive.
- `core/L0/p_create_{N}_to_{N+1}.npz` -> p-shell creation primitive.
- `LMSM/LMSM.npz` -> module 03-00 LSMS states and energy coefficients.
- `LSJM/LSJM.npz` -> module 03-01 LSJM states and energy coefficients.
- `IONED/states.npz` -> module 03-05 full single-ion ED eigenstates and
  absolute intermediate-sector energies.
- `L1/data.npz` -> $A^{\kappa,n}_{u j}, B^{\kappa,n-1}_{j v}$.
- `L2/data.npz` -> route factors
  $M_A$, $M_B$
  (or equivalent block/factorized representation with exact reconstruction metadata).
- SOPT `L3/data.npz` -> $h_{\mathrm{pre},j_3 j_4,j_1 j_2}^{(\mu)}$.
- FOPT `L3/data.npz` -> total `h_eff_4`, process-resolved `h_eff_4`
  stacked in process order `[P1,P2,P3,P4,P5]`, and total/process `J_mu` plus
  mapping residuals. Runtime FOPT exchange output requires a two-dimensional
  projected local space.
- FOPT `L3/exchange.txt` -> human-readable total and process-resolved `J_mu`
  rows; `data.npz` remains the machine contract.
- `L4/data.npz` -> $h_{\mu,abcd},\mathrm{Heff}_{abcd}^{(\mu)}$ and, when the
  projected local space is two-dimensional, optional `J_mu` + `mapping_residual`.
- SOPT `L4/exchange.txt` -> human-readable total `J_mu` row when `J_mu` is
  available; `data.npz` remains the machine contract.
- `spin12/data.npz` remains reserved for optional standalone post-processing and
  is not required by the current runtime.

Code form:
```text
artifact -> tensor_semantics mapping is mandatory metadata truth
```

Validation:
- Tensor semantics in `meta.json` must match this section.

## 6) Energy-Term Reconstruction Contract (MUST)
MUST:
- LMSM reconstruction:
  `E_lmsm = F0*coef_F0 + F2*coef_F2 + F4*coef_F4 + F6*coef_F6`
- LSJM reconstruction:
  `E_lsjm = F0*coef_F0 + F2*coef_F2 + F4*coef_F4 + F6*coef_F6 + zeta*coef_zeta`

Code form:
```text
E_lmsm(a) = sum_k Fk * coef_Fk[a]
E_lsjm(a) = E_lmsm(a) + zeta * coef_zeta[a]
```

Validation:
- Reconstructed energies must match stored energy views within runtime tolerances.

## 7) Metadata Contract (MUST)
MUST:
- Required `meta.json` fields:
  `schema_version`, `module`, `level`, `key`, `inputs_summary`, `tensor_name`,
  `physical_meaning`, `basis_id`, `index_definition`, `unit`,
  `storage_layout`, `dtype`, `logical_shape`, `payload_files`, `created_at`.
- If sparse: include `nnz`.
- If factorized: include exact reconstruction formula.

Code form:
```text
meta_required = {schema_version,module,level,key,inputs_summary,tensor_name,
                 physical_meaning,basis_id,index_definition,unit,
                 storage_layout,dtype,logical_shape,payload_files,created_at}
```

Validation:
- Missing required metadata is a hard contract error.

## 8) Key Contract (MUST)
MUST:
- `LMSM`: `{n, r42, r62, standard_version}` where `r42/r62` are derived from input `F2/F4/F6`.
- `LSJM`: `{keyLMSM, standard_version}`
- `L0`: `{n, standard_version}`
- `IONED`: `{n, U, Jh, F2, F4, F6, zeta, offset, scheme=ED, standard_version}`
- `L1` in `RS`: `{keyLSJM, fn_ground_subspace_id, standard_version}` and,
  when adjacent-sector LSMS/LSJM ratios differ from the legacy shared-ratio
  model, an additional deterministic branch signature
- `L1` in `ED`: `{keyIONED(n+1), keyLSJM(n), keyIONED(n-1),
  fn_ground_subspace_id, standard_version}`
- `L2`: `{keyL1, hopping_name, standard_version}`
- SOPT `L3`: `{keyL2, U, Jh, zeta, standard_version}` and, when adjacent-sector
  denominator parameters or main-sector reference mode differ from the legacy
  zero-reference shared-parameter model, an additional deterministic denominator signature
- FOPT `L3`: `{keyL2, U, Jh, lig1.U_p, lig2.U_p, kramer_name,
  projector_sha1, standard_version}` because FOPT consumes the low-energy
  projector `W` inside `L3`.
- `L4`: `{keyL3, kramer_name, projector_sha1, standard_version}`
- `spin12`: `{keyL4, kramer_basis_id, standard_version}`
- `hopping_name` and `kramer_name` are sourced from canonical normalization of
  `run_input.toml` `[sources].hopping_label` / `[sources].projection_label`
  into `[sources].hopping_name` / `[sources].kramer_name`
  and must be stable immutable tokens within one project cache namespace.
- When `[inputs].projector_file` is present, `projector_sha1` is the short
  content digest of that file and is included to prevent cache reuse after a
  projector file is edited without changing `kramer_name`.

Code form:
```text
key(level) = deterministic tuple per level contract
```

Validation:
- Key mismatch invalidates cache compatibility.

## 9) Read-First Cache Policy (MUST)
MUST:
- For every target artifact:
  1) compute path from key/tokens,
  2) if exists, validate and read,
  3) if missing/invalid, compute then atomically write.
- Runtime execution window is contiguous:
  `start_level ... end_level`, with
  `start_level,end_level in {LMSM,LSJM,L0,L1,L2,L3,L4}`
  and `start_level <= end_level`.
- Before execution from `start_level`, implementation must preflight-check
  required upstream artifacts and required window-input fields.
- Preflight upstream map:
  - `LMSM` requires `{}` (fresh compute allowed)
  - `LSJM` requires `{LMSM}`
  - `L0` requires `{}`
  - `L1` requires `{LMSM, LSJM, L0}`
  - `L2` requires `{L1}`
  - `L3` requires `{L2}`
  - `L4` requires `{L3}` for the materialized path, or `{L2}` plus
    denominator inputs and projector `W` for an equivalent fused SOPT L4 path
- Any missing/invalid required upstream artifact at preflight is a hard failure.
- Levels above `end_level` must not execute and must not write artifacts.
- Precompute-only run is represented by `end_level <= L2`.

Code form:
```text
if exists(target) and validate(target):
  load(target)
else:
  compute()
  atomic_write(target)

for level in [LMSM,LSJM,L0,L1,L2,L3,L4]:
  if level > end_level:
    skip(level)
```

Validation:
- Rewrite without validation is forbidden.
- Preflight violation is `FXE-IO-001/002`.

## 10) External Input Boundary (MUST)
MUST:
- `hopping` and `kramer` computational inputs are external runtime inputs.
- Snapshots under `./outputs/.../input_hopping.npz` and
  `./outputs/.../input_kramer.npz` are audit-only, never computational source.
- Missing external inputs must fail (no fallback to snapshots).

Code form:
```text
source_hopping = external_input_only
source_kramer  = external_input_only
```

Validation:
- Any fallback-to-snapshot behavior is a hard failure.

## 10.1) Stage-Local Exchange Text Export (MUST)
Human-readable exchange text output is stage-local:
- SOPT writes `exchange.txt` under the `L4` artifact directory when `J_mu` is
  available.
- FOPT writes `exchange.txt` under the `L3` artifact directory.
- Implementations must not write an additional shallow point-result text file
  directly under `output_root`.

## 10.2) Run Log Export (MUST)
Runs with `runtime.run_name` must write a run-level log at:

```text
<output_root>/<run_name>/run.log
```

The file log must include stage summaries even when console output is filtered
with a higher `--log-level`.

## 11) Search Index Contract (MUST)
MUST:
- Maintain append-only `./outputs/index.jsonl`.
- Each line includes at least:
  `key,module,level,path,created_at,n,r42,r62,U,Jh,zeta,hopping_name,kramer_name,content_hash` (when applicable).

Code form:
```text
append(index.jsonl, index_record)
```

Validation:
- Missing required index fields breaks traceability contract.

## 13) Parallel Persistence Rule (MUST)
MUST:
- Persistent artifact writing is single-writer only.
- The current reference implementation is serial-first; if a future runtime
  computes local shards, one designated writer must still assemble the full
  tensor/matrix before persisting.
- Level `04-03` (spin12) remains serial-only by default contract.
- Non-writer workers must not write stage `data.npz`/`meta.json`.
- Any runtime metadata persisted to `meta.json` must be consistent with the
  actual backend used.

Code form:
```text
local = compute(...)
full  = assemble_for_single_writer(local)
if writer_role:
  write(full, meta)
else:
  no_persist_write()
```

Validation:
- Concurrent writes to one artifact path are forbidden.
