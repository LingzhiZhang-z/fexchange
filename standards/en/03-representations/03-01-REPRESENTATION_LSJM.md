# 03-01-REPRESENTATION_LSJM

This file defines the LSJM representation contract and LSMS->LSJM transform.

## 1) State Definition
LSJM basis states are

Math:
$$
\lvert \alpha L S J M \rangle,
\qquad J \in [|L-S|,\,L+S],
\qquad M=-J,\ldots,J.
$$

Outputs use `twoS = 2S`.

## 2) Transform Rule from LSMS
Within each fixed `(alpha, L, S)` term block:

Math:
$$
\mathbf J = \mathbf L + \mathbf S,
\qquad
J_\pm = L_\pm + S_\pm,
\qquad
J_z = L_z + S_z.
$$

Operator conventions for $L/S/J$ are inherited from
`./standards/en/02-models/02-04-ANGULAR_MOMENTUM_OPERATORS.md`.

LSJM states are generated by a highest-weight method in this block, and then
expanded in the LSMS basis.
No mixing between different `LS` blocks is allowed in this model version.
Convention in this standard: each **column** of the transform matrix is one LSJM state.

MUST:
- Primary construction route is the $J_\pm$ highest-weight method in Section 2.1.
- CG-coefficient form is validation-only and does not replace Section 2.1 as the normative generator.

### 2.1 Highest-Weight Generation by $J_\pm$ (MUST)
For each fixed `(alpha,L,S)` block:

1. Build LSMS subspaces at fixed $M=M_L+M_S$.
2. For each $J$ (descending from $L+S$ to $|L-S|$), in the $M=J$ subspace solve
Math:
   $$
   J_+ \lvert \psi \rangle = 0.
   $$
3. Remove components already spanned by previously constructed higher-$J$
   multiplets at the same $M$ (orthogonal projection).
4. Normalize the remaining vector to define
   $\lvert \alpha L S; J,J\rangle$.
5. Generate the full multiplet via
Math:
   $$
   \lvert \alpha L S; J,M-1\rangle
   = \frac{1}{\sqrt{(J+M)(J-M+1)}}\,J_-\lvert \alpha L S; J,M\rangle.
   $$

Numerical expectation after projection:
- at target $(J,M=J)$, kernel dimension should be 1;
- otherwise treat as implementation/tolerance error.

### 2.2 Equivalent CG Form (Validation-only, Non-Normative Generation Route)
The generated states must be equivalent to the CG-coupled form:

Math:
$$
\lvert \alpha L S J M \rangle
= \sum_{M_L,M_S}
\langle L M_L; S M_S \mid J M \rangle
\lvert \alpha L M_L S M_S \rangle.
$$

Define the CG matrix $C^{(L,S)}$ with LSMS row index `(M_L,M_S)` and LSJM
column index `(J,M)`:

Math:
$$
C^{(L,S)}_{(M_L,M_S),(J,M)}
= \langle L M_L; S M_S \mid J M \rangle,
\quad \text{with } M=M_L+M_S.
$$

Equivalent sparse rule:
- if $M_L+M_S\neq M$, matrix element is zero;
- if $M_L+M_S=M$, use the CG value above.

Global transform is block diagonal over `(alpha,L,S)`:

Math:
$$
U_{\mathrm{LSMS}\to\mathrm{LSJM}}
= \mathrm{blockdiag}\!\left(U^{(L,S)}\right)_{\alpha,L,S},
$$

where each $U^{(L,S)}$ is built by the $J_\pm$ generation above.

Code form:
```text
for each (alpha,L,S) block:
  build M-subspaces from LSMS columns
  for J from L+S down to |L-S|:
    solve nullspace(J_plus at M=J), project out higher-J components
    normalize highest-weight state |J,J>
    generate |J,M> by J_minus recursion
assemble block U_LSMS_to_LSJM (columns are LSJM states)
```

## 3) Fock-Space Matrix Contract
If

Math:
$$
V^{\mathrm{LSMS}} \in \mathbb{C}^{d_{\mathrm{fock}}\times d_{\mathrm{lsms}}},
\qquad
U_{\mathrm{LSMS}\to\mathrm{LSJM}} \in \mathbb{C}^{d_{\mathrm{lsms}}\times d_{\mathrm{lsjm}}},
$$

then

Math:
$$
V^{\mathrm{LSJM}} = V^{\mathrm{LSMS}} U_{\mathrm{LSMS}\to\mathrm{LSJM}}.
$$

Storage contract:
- `V_fock.shape = (dim_fock, n_lsjm_states)`
- column `a` is one LSJM state.

### 3.1 Downstream Kramer-Binding Contract (MUST)
MUST:
- LSJM outputs must provide deterministic `j`-subspace ordering metadata for downstream `W` binding in `04-02`.
- If SOC-lowest subspace projector is exported (`U_n_soc0` or equivalent), its columns must follow that same `j_order_id`.

Code form:
```text
lsjm_meta_required = {basis_id, orbital_order_id, j_order_id, n_j}
U_n_soc0.shape = (dim_fock_n, n_j)   # optional export, if present
```

Validation:
- Any downstream `W` input must satisfy `W.shape[0] == n_j`.
- Missing `j_order_id` or inconsistent `n_j` is a hard interface failure.

## 4) Label Contract (MUST)
Per LSJM state column, labels MUST include:
- `alpha`
- `L`
- `twoS`
- `J`
- `M`

Optional text term labels are allowed.

## 5) Canonical Ordering (MUST)
LSJM column order is deterministic:
1. term order inherited from LSMS parent terms
2. within each term: `J` ascending
3. within each `J`: `M` ascending

## 6) Energy Contract
LSJM energy output MUST be term-decomposed and aligned one-to-one with LSJM columns.

Required per-column coefficients:
- `coef_F0`
- `coef_F2`
- `coef_F4`
- `coef_F6`
- `coef_zeta`

### 6.1 Operator-Expectation Rule (MUST)
Use operator expectations in the LSJM states to define energy coefficients.

For LSJM state column $a$ with vector $\lvert \psi_a^{\mathrm{LSJM}}\rangle$:

Math:
$$
\mathrm{coef\_F_k}[a]
=
\langle \psi_a^{\mathrm{LSJM}} \rvert \hat O_k \lvert \psi_a^{\mathrm{LSJM}} \rangle,
\quad k\in\{0,2,4,6\}.
$$

Math:
$$
\mathrm{coef\_zeta}[a]
=
\langle \psi_a^{\mathrm{LSJM}} \rvert \hat O_{\mathrm{soc}} \lvert \psi_a^{\mathrm{LSJM}} \rangle,
\qquad
H_{\mathrm{soc}}=\zeta\,\hat O_{\mathrm{soc}}.
$$

`coef_F0/F2/F4/F6` may be inherited from LSMS output or recomputed directly in
LSJM basis, but both paths MUST match within tolerance.

### 6.1.1 Fixed Coulomb Reference Scale for LSJM Internal Ordering (MUST)
When LSJM stage logic needs a Coulomb-only reference for deterministic ordering
or consistency checks inside a fixed $n$ sector, it MUST use the same
normalized convention as LSMS:
- $F^0=0$,
- $J_H=1$,
- $r_{42}=F^4/F^2$, $r_{62}=F^6/F^2$,
- $F^2=6435/(286+195r_{42}+250r_{62})$,
- $F^4=r_{42}F^2$, $F^6=r_{62}F^2$.

This rule keeps LSMS/LSJM ordering independent of absolute $U$.

Important:
- This does NOT replace the absolute-energy reconstruction contract in Section
  6.1 for downstream cross-sector denominators.
- Cross-sector absolute energies still use $F^0=U$ from runtime input
  (`00-05` contract).

For LSJM state column `a`, total energy is reconstructed by

Math:
$$
E^{\mathrm{LSJM}}_a
=
F0\cdot \mathrm{coef\_F0}[a]
+ F2\cdot \mathrm{coef\_F2}[a]
+ F4\cdot \mathrm{coef\_F4}[a]
+ F6\cdot \mathrm{coef\_F6}[a]
+ \zeta\cdot \mathrm{coef\_zeta}[a].
$$

For fixed `(alpha,L,S,J)`, all `M` components are degenerate before CEF.

### 6.2 Diagonal-Subspace Checks (MUST)
In the LSJM basis, projected matrices must be checked for off-diagonal leakage.

Per fixed `(alpha,L,S)` block:

Math:
$$
\left(H_{\mathrm{soc}}^{\mathrm{blk}}\right)_{ab}
=
\langle \psi_a^{\mathrm{LSJM}} \rvert \hat O_{\mathrm{soc}} \lvert \psi_b^{\mathrm{LSJM}} \rangle.
$$

SOC-diagonalization requirement:

Math:
$$
\max_{a\neq b}
\left|
\left(H_{\mathrm{soc}}^{\mathrm{blk}}\right)_{ab}
\right|
\le \varepsilon_{\mathrm{diag}}.
$$

Also check Coulomb consistency in LSJM basis:

Math:
$$
\left(H_{\mathrm{int}}^{\mathrm{LSJM}}\right)_{ab}
=
\langle \psi_a^{\mathrm{LSJM}} \rvert H_{\mathrm{int}} \lvert \psi_b^{\mathrm{LSJM}} \rangle,
$$

and require off-diagonal leakage to be numerically small in the target
subspace.

### 6.3 Optional LS-Coupling Cross-Check (Non-Normative)
Under fixed-`LS` approximation, for the $n=1$ case one may compare
`coef_zeta` against

Math:
$$
\mathrm{coef\_zeta}(\alpha,L,S,J,M)
= \frac{1}{2}\left[J(J+1)-L(L+1)-S(S+1)\right].
$$

For general $f^n$ ($n>1$), do not hard-code the $\tfrac{1}{2}$ prefactor in this
cross-check. If a compact reference form is used, write

Math:
$$
\mathrm{coef\_zeta}
=
\eta_n\left[J(J+1)-L(L+1)-S(S+1)\right],
$$

with $n$-dependent factor $\eta_n$ determined by the chosen model/projection.

This section is diagnostic only; implementation authority for energy
coefficients remains Section 6.1.

## 7) Validation
- Orthonormality: `V_fock^\dagger V_fock = I` (within tolerance).
- Label-state count match.
- `basis_id` consistent with LSMS/Fock source.
- No inter-`LS` mixing in transform blocks.
- Energy coefficients must follow Section 6.1 operator-expectation rule.
- Off-diagonal checks for projected `H_soc`/`H_int` must satisfy Section 6.2.
- In each `(alpha,L,S,J)` multiplet:
  - ladder consistency with $J_-$ recurrence;
  - generated vectors must match CG form up to phase.
