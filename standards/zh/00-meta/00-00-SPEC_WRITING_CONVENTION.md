# 00-00-SPEC_WRITING_CONVENTION

本文件定义面向 AI 阅读的规范写作约定。

## 1) 适用范围（MUST）
- 本约定适用于 `./standards/en/` 与 `./standards/zh/` 下所有规范文件。
- 物理/模型内容仍写在后续分层规范中；本文件只定义写作形式。

## 2) 单条规则结构（MUST）
每条非平凡规则建议按以下顺序书写：
1. `MUST` 列表（硬约束）。
2. `Math:` LaTeX 公式块（`$$ ... $$`）。
3. `Code form:` 单行 ASCII 代码形态。
4. `Index:` 显式说明符号/指标含义。
5. `Validation:` 最小校验项。

## 3) 公式书写（MUST）
- 优先使用块级公式（`$$ ... $$`），避免过长行内公式。
- 长公式应拆分为多段块级公式，或使用对齐写法。
- 不允许跨很远段落隐式借用符号；关键符号应在本节重声明。

## 4) 指标约定（MUST）
- 指标命名在全规范中应保持一致。
- 若某节存在局部指标约束，必须在公式前明确声明。
- 若同名指标含义变化，必须改名，不得复用。

## 5) 与代码映射（MUST）
- 每个核心公式必须附一行 `Code form`，可直接映射实现。
- `Code form` 使用可解析的纯文本，不使用仅符号化缩写。

## 6) 跨文件引用
- 跨文件路径统一写为 `./standards/en/...` 相对路径。
- 领域文件可用一行引用本文件，避免重复写格式政策。
